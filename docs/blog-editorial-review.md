# 博客编辑检查与首批修订

## 目前的问题

检查范围：125 篇 Markdown / MDX 内容。简单文本扫描中，92 篇含“很多人”，54 篇含同一行的“不是……而是”，51 篇含“真正”。这些数字只提示重复，不能单独判断文章好坏。

主要有两种写法：

- 清单式怀旧：一个场景拆成十来个表情标题，每句话单独成段，列举物件，再解释它们代表的情感，结尾邀请读者分享。网吧、停电、小卖部、千千静听最明显。
- 模拟私人随笔：段落虽然连贯，却用未经确认的家庭经历、报价、人物对话、用户故事增加可信度。旧电脑中的家庭配置与购买经历、QQ 宠物中的最后一次喂食故事，需要作者核实，不能作为已知事实沿用。

另有事实风险：QQ 宠物原文对死亡机制前后不一致，把购买物品概括为都需要 Q 币；眼保健操把不同学校、不同年代的安排写成统一情况。首批删去不影响文章主题且未经核实的断言。没有对全站年代、产品机制、视频和外链完成事实核查。

已改七篇：

- first-internet-cafe：聚焦找机位、上机、下机；去掉百科式清单与重复升华，题目改为“走进网吧的时候”。
- old-computer：去掉未经确认的“我家”、价格、配置、父亲对话及“去年”经历；题目改为“家里的那台电脑”。
- qq-pet：保留喜欢又嫌烦的矛盾，去掉不可靠的养成机制描述和无来源的关服告别故事。
- eye-exercises-recess：去掉一概而论的录音、体操版本、课间时长与夸大的“社交密度”。
- after-school-store：围绕钱不够、选东西、等同学展开，删去商品目录与人生道理。
- power-outage-night：保留热、烦、错过电视、搬椅子等不那么美好的部分。
- qianqian-listen-mp3：保留文件失效、命名混乱、歌词不同步和换皮肤的折腾。

文章路由、日期、分类、标签与已有媒体配置不变。移除首批部分泛泛“资料补充”段落，原始链接可在 Git 历史查看；没有把原链接当成已经核实的事实来源。

## 后续写作标准

1. 个人经历必须有作者提供的依据。暂缺素材时写非自传式场景短文，不能用虚构的父母、同学、年份、价格冒充作者回忆。
2. 一篇围绕一两件事展开，物件必须参与动作，不能只在清单中出现。
3. 允许无聊、嫌弃、失望、记不清。过去不用处处比现在好。
4. 普通段落自然连起来；列举、标题、短句按内容需要使用，不机械禁用。
5. 结尾可以停在一个动作，不要求总结时代、青春、人与世界的关系。
6. 删除一句议论后，如果场景仍然成立，就优先让场景自己说话。
7. 有文学感不等于增加比喻；口语感也不等于加语气词、错别字或故意写糙。
8. 产品机制、历史时间、具体录音及引述要另做核实。没有查过的内容，不能用肯定语气补齐。

## 下一轮

首批是编辑方向样稿，尚未完成其余 118 篇。优先处理有未经确认第一人称经历的文章，再按主题逐篇调整清单式文章，避免批量替换后出现另一种统一腔调。

作者若愿意补充，每篇只需提供：一个实际发生过的片段、一个当时嫌烦的小事、一处记不清的地方。这些材料比统一“润色”更能形成个人声音。

## 第二轮：三篇风格试写

用户认为第一轮“太轻”，要求参照汪曾祺的写法试写。已再次修改 after-school-store、power-outage-night、old-computer。用更完整的场景、物件的使用过程和人物之间的往来承载感情，减少编辑式解释。

这三篇是文学性试写，不是作者回忆的事实稿。小卖部老板的眼镜、赊本子对话、两个孩子分酸梅粉、停电时分西瓜、熟人修电脑等新增场景与人物均属虚构，不应在后续编辑中误当作用户已确认的经历。正式作为私人博客回忆发表前，需要作者替换或确认素材；也可明确保留为虚构随笔。

## 第三轮：用作者提供的经历重写两篇

用户已提供小卖部和停电的真实素材。after-school-store 与 power-outage-night 的第二轮虚构稿已被替换；上节有关虚构老板、赊账、分西瓜等说明仅适用于历史版本，不再描述这两篇当前正文。电脑稿暂不改动，仍是待替换的文学试稿。

- 小卖部：只大一岁但应称叔叔的亲戚；一年级、胆小腼腆；大人前夜嘱托；次日用一元买回两手捧着、放满桌子的零食；后来遗憾没分给同样是孩子的叔叔。没有添加商品名、店主或对话。“一块钱的零食”为新标题，路由不变。
- 停电：电视与电扇静下来后听见蝉鸣；新鲜、冷峻、清醒和黑暗中的脆弱；微弱烛光的温暖；与父母在三楼平房上铺凉席；夜深的风与风停后的蚊子。没有续用前一稿的邻居、分瓜等虚构情节。
- 写法：围绕每篇最有分量的记忆展开，不再补齐完整时代景观。结尾的现在时感受属于代拟文字，仍供作者判断是否准确表达本人。

## 第四轮：小卖部的主次调整

按作者反馈，叔叔与未分零食的遗憾只作引子、配角，占开头三段。正文转向有限零花钱下的挑选、问价、临时改主意、小包装的吃法、陪同学逛店等可共感场景，结尾回到作者确实提供的“满桌零食”。后半部分为一般场景的文学描写，不新增作者确定经历过的个人事件。摘要同步改为以小卖部和一块钱为中心。

## 第五轮：以儿童的感受和想象为中心

作者指出上一稿仍然使用成人的盘算逻辑。删除问价、性价比、挑选策略等主线，转向未得到时的眼馋与想象、得到后的满足，以及并不匮乏时也会自发生出的愿望。原始个人经历保持不变，新增一般场景不写成作者确定做过的事。后续编辑应优先关注当时感到什么、由此想到了什么，而非替孩子解释理性的动机。

## 第六轮：羊肉串新篇与儿童感受的延续

新增 lamb-skewers-gloves，依据作者提供的真实片段：冬天，父亲骑自行车、作者坐横梁；露指头棉手套；一元一串、五串；父母合吃一串、作者吃四串；羊肉蹭在手套上，之后几天上学写作业闻到仍开心；告诉母亲后，过几星期母亲又让父亲带去买。没有追加店址、肉的调味、家人直接引语或未洗手套的刻意行为。

同时再修 after-school-store 与 power-outage-night，去掉成人对心理的分类、算计与事后评论，让满足和凉快在当时的感觉里停留。小卖部的叔叔维持引子位置；停电保留作者提到的复杂感受与蚊子，避免为“单纯”抹掉事实。三篇中延展感受的措辞仍属代拟，需作者审阅。

本轮只试改有作者具体素材支撑的另外两篇。其余已改文章、尚未改的文章不视为通过本轮文风审阅，尤其电脑篇仍待作者提供经历。

## 第七轮：其余文章的全站复审

按作者确认的方向检查现有 126 篇：本轮修订 121 篇正文和摘要，保留三篇已认可的真实素材稿、眼保健操与课间稿；电脑篇已读但不继续扩写，仍待作者补素材。具体处理记录见 [全站文章文风复审](./blog-full-review.md)。

- 生活、玩具类围绕具体的盼望、玩耍、凉快和满足；删除成本盘算、社交货币、成长寓意与反复解释怀旧的段落。
- 音乐、影视、游戏各留自己的观看与操作感受，不强行套入作者的童年履历。技术题材保留日常用法与真实的不顺，不作技术史或使用教程。
- 未获确认的第一人称家庭故事、人物对白、年代价格与后来的聚会见闻不沿用。一般场景为文学代拟，并不意味着作者逐件亲历。
